# Hexicon promo video

A ~53 s LinkedIn video that walks through the whole project using **real screenshots of the live site**, built with [Remotion](https://www.remotion.dev/) and the shot recipes of the `video-shotcraft` skill.

```bash
cd video
npm install
npm run build --prefix ..   # the site must be built: capture reads ../dist
npm run capture             # real 2x screenshots + src/layout.json (uses local Edge)
npm run audio               # copies music + sound effects into public/audio
npm run dev                 # Remotion Studio preview
npm run render              # out/hexicon-promo.mp4 (with music)
npx remotion render src/index.ts HexiconPromo out/hexicon-promo-nobgm.mp4 --props=props-nobgm.json
```

`public/`, `out/` and `node_modules/` are git-ignored; everything in them is regenerated by the commands above.

## Brief

| Audience | Security practitioners, learners, recruiters scrolling a feed, often muted |

| Format | 1920×1080, 30 fps, ~53 s, no voice-over: captions carry the story (≥ 56 px so they survive a phone-sized feed) |

## Visual direction

The film uses Hexicon's own "Midnight Cartographer" design system (tokens copied from `site/styles.css` into `src/theme.ts`): navy `#0B1020`, brass `#E8A33D`, teal `#2DD4BF`, cream text, **Fraunces** headlines, **Inter** body, **JetBrains Mono** kickers, the faint contour lines of the hero. The skill's paper-and-ink template look was not used; only its motion grammar and timings were reused, re-skinned dark.

Motion personality: *professional & trustworthy* preset nudged calmer: ~21 f main moves, no overshoot on plain fades, real overshoot (bezier y1 > 1) only where things physically land.

## Deliberate deviations from the recipes

- **theme-switch-moves runs four times** (card: ≤ 1 theme switch per film). Here the sweep *is* the feature, one language per sweep, each followed by a hold. The Arabic capture mirrors the layout, which is the point of that beat.
- **list-stack-press with 10 cards uses accelerating cues** (R2) instead of the card's even 12 f beat for 5 cards; per-card highlight bars dropped (a single glaze across the stack instead, Q4).
- **No music beat-sync.** The user did not pick a track; the bed is mixed under the SFX and cuts are not locked to beats.
- **Captions are 58 px** (Q11) rather than the template's 22 px mono strip.
